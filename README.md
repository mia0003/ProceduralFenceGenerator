## Project 1 Final: The Fence Generator

## Description
A procedural fence generator for Maya.

## Features
- Procedural fence generation 
- Procedural beveling 
- Automatic grouping of assets
- Automatic fence cleanup 

## Parameters
- Number of Posts
- Post Height
- Post Spacing
- Number of Rails
- Post Width
- Fence Options

## How to Use
1. Launch the tool from the shelf button.
2. Adjust the fence parameters to user's preference.
3. Select a fence option.
4. Click Generate Fence.
